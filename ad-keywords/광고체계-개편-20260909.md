## 되돌리는 법

직전 상태는 `ad-keywords/실업급여그룹_입찰_직전스냅샷_20260909.json`에 98개 전부 저장돼 있다.

```python
# skills/네이버광고/scripts 에서
import json
from nv import req
G = 'grp-a001-01-000000071956635'
snap = json.load(open('.../실업급여그룹_입찰_직전스냅샷_20260909.json', encoding='utf-8'))
body = [{'nccKeywordId': k['nccKeywordId'], 'nccAdgroupId': G,
         'bidAmt': k['bidAmt'], 'useGroupBidAmt': False}
        for k in snap if k['bidAmt'] and k['bidAmt'] > 70]
req('PUT', '/ncc/keywords', {'fields': 'bidAmt'}, body)
```

## 하지 않은 것과 그 이유

- **일예산 20,000 → 30,000 상향은 보류했다.** 입찰을 내리면 실업급여 쪽 지출이 먼저 줄어
  같은 20,000원 안에서 좋은 그룹으로 돈이 옮겨 간다. 예산까지 동시에 올리면 어느 것이 들었는지
  가릴 수 없고 지출만 는다. 며칠 재고 그때 올린다.
- **실업급여 그룹·키워드 중지는 하지 않았다.** 위에 적은 대로 실제 손님이 나온 길이다.
