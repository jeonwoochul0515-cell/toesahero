# 07 · 공개 화면(홈·랜딩·FAQ·칼럼) 점검

네이버 광고를 누르고 처음 들어온 직장인(비개발자, 휴대폰, 급하고 불안함)의 눈으로
공개 화면의 글자와 버튼 동작을 코드로 끝까지 따라간 기록이다.
수정·커밋은 하지 않았다. 화면 실행·브라우저 확인 없이 소스만 읽었다.

### 7. 가격 다섯 종류가 서로 겹쳐 무엇을 사야 할지 알 수 없다 · 심각도 답답

- **무슨 일이** 한 화면에 상품이 다섯 개다 — 19만 9천 / 39만 / 79만 / 88만 / 66만.
  그런데 **표준 절차(39만)에도 "퇴직금·연차수당 산정 자문", "노동청 진정 1건 자문"이 들어 있고**,
  임금·퇴직금 회수(88만)의 내용도 "고용노동청 진정 대리 자문"이다. 손님 입장에서 둘의 차이를 읽어낼 수 없다.

  게다가 「상담료」 칸은 "초기 카톡 문의 후 안내"라서, **상담부터 돈이 드는지 아닌지조차 알 수 없다.**

## 확신이 낮은 항목

- **19번(탭 타깃·글자 크기)** — 이번 점검은 `.tsx/.ts`만 읽었고 CSS 파일은 보지 않았다.
  `line-height`와 `.btn` 기본값에 따라 실제 높이가 44px를 넘을 수 있다. 실제 화면에서 재야 확정된다.
- **상단 메뉴의 휴대폰 동작** — `Nav.tsx`에 햄버거 메뉴나 접는 장치가 **코드상 전혀 없다**.
  좁은 화면에서 `.links`가 CSS로 숨겨진다면 홈에서도 FAQ·칼럼·계산기·마이페이지로 갈 길이 사라진다.
  CSS를 못 봐서 단정하지 못한다 — 휴대폰에서 한 번 열어 확인할 것.
- **8번(노무사 비교)** — 변협 규정 원문을 확인하지 못했다(협회 자치규정이라 법제처 API에 없다).
  변호사 김창희의 판단이 필요하다. 내용 자체는 변호사법 §109에 근거한 사실 서술이다.
- **9번("무료" 표기)** — 무료로 제공하는 것이 **법률상담이 아니라 서식·계산기**라 규정 위반이 아닐 수 있다.
  다만 FAQ의 자기 선언과 어긋나는 점은 표기 문제로 확실하다.
- **2번(FAQ 버튼)** — 홈으로 이동한 뒤 어떤 사정으로 대화창이 열리는 경로가 있는지 찾아봤으나
  `open-chat` 이벤트를 쏘는 코드가 그 경로에 없었다. 실제 화면에서 한 번 눌러 확인하면 확정된다.
- 히로가 광고 검색어를 되읽어 첫인사를 거는 장치(`src/lib/entry.ts`, `hiroSpeech.ts:73-77`)는
  잘 만들어져 있으나, `attribution.js`가 실제로 `n_query`를 저장하는지는 `.js` 파일이라 읽지 않았다.
