페르소나 — 실제 접수 두 건.

  "계약서에 무서운 조항이 있어요"를 두 번 말했으나 챗봇이 회수 못 하고 끊김.
- **yuri.m** 입사 3주, 불안증·공황으로 퇴사 의사를 못 꺼냄. 카카오 채널 유입. 기본 절차 199,000원.

사무실 — 실무 전우철 / 담당변호사 김창희.

## 1차 발견 (코드 추적, 2026-09-12)

### 당장 막히는 것
- [ ] ① 결제 후 「내 사건 보기」가 빈 화면 — 로그인 없이 결제하면 사건이 계정에 안 붙고, 나중에 로그인해도 안 따라옴
- [ ] ② 위임장 서명 화면으로 가는 길이 손님 화면에 없음
- [ ] ③ 위임장 제출이 결제·접수 건과 연결되지 않음 (사람이 손으로 맞춤)
- [ ] ④ 올린 자료를 본인이 못 지움 — 저장소는 삭제 가능, 목록은 불가라 반쪽 삭제 위험
- [ ] ⑤ 결제 실패로 돌아와도 안내가 없음

### 매일 쓰다 보면 답답한 것
- [ ] ⑥ 챗봇이 되묻고 나서 정형 안내로 대화를 덮음 (호객꾼 스킬 §6-1 정책은 세웠으나 코드 미반영)
- [ ] ⑦ 중앙 접수함(lead-inbox)에 같은 세션이 여러 건으로 쌓임
- [ ] ⑧ 진행 상황을 보려면 로그인이 필요한데 결제 전에 안 알려줌

### 말이 어렵거나 불안하게 하는 것
- [ ] ⑨ 손님 화면에 "결제 인프라 미설정" 같은 개발 용어
- [ ] ⑩ 본인확인 실패 시 영어 오류 코드를 손님이 옮겨 적게 함
- [ ] ⑪ 접수 경로 이름에 상품명·서류명이 섞임("베이직: 통보문")

1. 결제·접수를 전화번호로 계정에 잇기 (①⑧)
2. 결제 실패 안내 (⑤)
3. 위임장 가는 길 + 사건 연결 (②③)
4. 올린 자료 본인 삭제 (④)
5. 챗봇 질문 직후 정형 안내 억제 (⑥)
6. 중앙 접수함 세션 단위 갱신 (⑦)
7. 손님 화면 말 다듬기 (⑨⑩⑪)
